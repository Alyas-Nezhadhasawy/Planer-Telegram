## 📖 معرفی

این ربات به شما کمک می‌کند تا برنامه‌های **بلندمدت** خود را با تسک‌های **روزانه** مدیریت کنید، پیشرفت خود را ثبت کنید، تست‌های روزانه را ثبت و تحلیل کنید و گزارش‌های **خودکار** را برای **مشاور** ارسال کنید.

**ویژگی‌های کلیدی:**
- ✅ برنامه‌ریزی بلندمدت با تاریخ شروع و پایان و تسک‌های مخصوص هر روز
- ✅ توزیع هوشمند زمان مطالعه بر اساس سطح سختی (با استفاده از AI)
- ✅ ثبت گزارش روزانه (ساعت بیداری، خواب، وضعیت روحی، انرژی، سوالات دلخواه)
- ✅ مدیریت تسک‌های روزانه (ثبت انجام/انجام‌نشده)
- ✅ ثبت تست‌های روزانه (تعداد کل، غلط، درصد صحت)
- ✅ ارسال خودکار گزارش به مشاور هر شب ساعت ۱۱ به وقت تهران
- ✅ ارسال فوری گزارش با دستور `/ft`
- ✅ تنظیم گروه مشاور برای ارسال گزارش‌ها
- ✅ پشتیبانی از هوش مصنوعی (Gemini، OpenRouter، python-tgpt) برای تولید برنامه روزانه
- ✅ سیستم مدیریت کاربران (مالک، ادمین، کاربر عادی)
- ✅ اعلام خودکار استارت ربات توسط کاربران جدید به مالک
- ✅ دستور `/adduser` برای افزودن کاربران جدید توسط مالک
- ✅ پایگاه داده SQLite برای ذخیره دائمی اطلاعات

## 🚀 روش‌های نصب و اجرا

### روش اول: اجرا روی سیستم محلی (VPS یا لوکال)

#### ۱. پیش‌نیازها

- Python 3.10 یا بالاتر
- pip
- یک ربات تلگرام (ساخته شده توسط [@BotFather](https://t.me/BotFather))
- کلیدهای API (اختیاری) برای هوش مصنوعی

#### ۲. نصب

```bash
# کلون کردن مخزن
git clone https://github.com/your-username/telegram-planner-bot.git
cd telegram-planner-bot
pip install -r requirements.txt
```
